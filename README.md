# 校园三年 · 风经过座位

## v11 周末生活

工作日三段结束后进入周六、周日，每天两段：可以安排两件小事，或用全天做一件事，也可留白恢复精力。18 项活动随进度开放，包括三次投篮、吃早饭、买菜、做饭、图书馆、散步、讲题、慢跑、书店短工、旧书摊、拍街景、电影、社区整理、修台灯、写信、画速写、选纸和条件同行。大多数为带头像的场景对白与选择，投篮为本轮新增实时小游戏。

零用钱、收支、信件和周末进度随存档保存。接球暗号会实际辅助下一次投篮，其他生活纪念可从“口袋里的东西”回看。和林遥同行只在明确选择靠近路线后开放；当前仍未确认恋爱，表白与其后的专属功能留到后续剧情。

新增轻点击、确认音；暂停菜单可独立关闭，设置保留。旧存档兼容；已经玩到六周结尾的旧进度，可点击“补完这个周末 · 保留六周进度”，会先在本浏览器留备份。已做过的新周末不能重复刷。

未来剧情标准、已做与未做需求见 [周末玩法与后续制作标准](DESIGN-WEEKENDS-V11.md)，本轮验证范围见 [VERIFICATION-V11.md](VERIFICATION-V11.md)。当前仍到第六个关键周，尚未加入运动会当天或三年结局。在线试玩：[周末生活版](https://zuozhu0417-art.github.io/campus-three-years-play/?v=11-weekends)。

## v10 配音开场

21.2 秒连续动作片头已加入参考音色合成对白。首次打开点“走进那年九月”有声播放，结尾用约 1.15 秒渐隐接回首页；跳过也会用约 0.65 秒同时淡出画面和声音。首页可重看，原男女主角选择与存档继续保留。手机竖屏、横屏和小屏有对应布局。

短片为生成画面与 AI 合成声音，不代表参考视频作者为本作录音或背书。此次没有做人物口型同步；剧情内的其余对话仍以文字和立绘呈现。验证见 VERIFICATION-V10.md。

片头按教室、留座、画海报、雨中等候四个镜头展开。短片 H.264/AAC，1280×720、30 fps，约 5 MB。首次打开等待点击后播放，手机竖屏完整保留画面，横屏可看得更大；加载失败时保留原静音画布演出和进入游戏入口。减少动态偏好下不自动展示片头，仍可主动重看。

观看标记独立于剧情存档，不消耗时间或精力。当前仍是六个关键周，尚未新增第七周和后续结局。历史 v5 的 18.8 秒分层动画素材与验证记录保留供回溯。

## 开始游戏

双击 **开始游戏.bat**，或使用 Edge / Chrome 打开 **index.html**。收到 ZIP 后先完整解压，保留整个文件夹。玩游戏无需安装依赖、联网或启动服务器。

点“推开教室的门”开始新周目：先选择女生或男生，再填写名字。没有预选性别，两种身份的初始能力、时间和精力相同，均可认识同一群人。选择会影响主角立绘、头像、名字和手记，尚无两套完全独立的性别专属剧情。

已有 v1 / v2 进度可点“继续游戏”；缺少身份时会先让你选择，再继续原有周数、约定和能力，不会强制改为男生。原存档键保留。

## 原有玩法

- 大立绘、姓名、独立头像、逐字对话、选择和回看。点正文、空格或 Enter 继续；“读完本段”快速到选择。
- 原有六段插画 CG：报到、递笔记、班旗、热饭、跑步、雨中等候，分别为 5 / 5.5 / 6 / 4.5 / 3 / 5 秒。插画运镜、粒子和光线属于页面演出，与人物 WebM 短片分开。
- 操场 400 米节奏跑：光点进入中央区域时按空格或点“落脚”。22 秒内跑完为成功，乱按减速；超时有独立结果。
- 晚自习手机躲避：空格或按钮切换拿出 / 收起，避开老师视野，18 秒内看完 3 条消息。被发现会进入老师谈话并记入手记。
- 小游戏按 Esc 暂停，可返回场景；切出窗口自动暂停。中途返回不扣资源，完成或失败只结算一次。

## 时间和精力

| 活动 | 基础精力变化 | 时间 |
|---|---:|---:|
| 第一 / 二 / 三次学习 | −26 / −30 / −34，基础学习收益递减 | 各 1 段 |
| 和赵程 / 林遥相处 | −12 | 1 段 |
| 跑步 | −14 | 1 段 |
| 晚自习看手机 | −8 | 1 段 |
| 早点睡 | +36 | 1 段 |
| 陪妈妈吃饭 | +10 | 1 段 |
| 独自 / 同桌吃饭 | +16 / +8 | 1 段 |
| 周末未安排的空闲 | 每段 +3 | 结束当天 |
| 跨周自然恢复 | +12 | 推进一周 |

精力上限 100，初始 64。精力不足不能开始消耗精力的活动，返回不扣时间。按学习 / 社交计划行动会多一点相应收获，按休整计划会额外恢复 3 精力。餐盘、睡觉、同一位朋友等每周各一次；学习可在教室或家里继续加练，两处共用次数。

例如初始连续学两段，精力剩 8，第三段加练需要 34：这时要把最后一段留给恢复，也没有时间再去陪所有人。班旗和笔记的约定需要提前给下一周留余力。

## 操作与保存

- 场景中 `1 / 2 / 3 / 4`：教室 / 食堂 / 操场 / 家里；`J` 手记，`P` 本周安排，Esc 暂停菜单。移动与在家看消息免费。
- Tab 选按钮，Enter 确认；小游戏可点击操作。手柄与改键界面未实现。
- 自动保存到当前浏览器。更换浏览器、移动文件夹或清除浏览器数据可能影响存档读取。菜单和结尾可导出 JSON，本版还没有导入恢复界面。
- 游戏内环境声默认关闭，右上角“声”开启程序合成的低音量风声；配音开场通过点击开始有声播放，片头内可单独静音。
- 轻点击音默认小音量开启；暂停菜单“点击音效”独立切换并保存，与环境声和片头静音分开。

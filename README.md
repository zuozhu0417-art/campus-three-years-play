# 校园三年 · 风经过座位

第一章校园生活试玩。可选男女主角，包含四个关键周、分支对话、人物表情短片、精力安排、跑步与晚自习手机小游戏。

## 本地运行

用 Edge / Chrome 打开 index.html。无需安装依赖或运行构建命令。

## 手机

通过本仓库的 GitHub Pages 地址打开，建议横屏。进度仅保存在各自浏览器，清除浏览器数据可能丢失进度。

## 交付范围

当前是第一章试玩，不是完整三年。两秒人物短片由生成的表情帧合成，不是连续动作 AI 视频。没有配音或口型同步。
